# RUSSIA.VISACENTER.COM

GitHub-ready starter for a Russia visa application service website.

## Included
- Public homepage with visa application selector
- Application/tracking UI
- Admin login at `/admin/login`
- Admin dashboard starter
- Admin application list/status UI
- Secure environment-variable configuration
- Responsive design

## Important
This project is a starter application. Before accepting real visa applications or payments, connect a real backend/database, authentication provider, document storage, payment gateway, email/SMS provider, and verify all visa/legal information.

## Local run
This starter is static and can be previewed by opening `public/index.html`.
For a production deployment with secure admin authentication, use the backend/auth implementation of your chosen hosting stack.

## GitHub
1. Create a private repository if you want the source code kept private.
2. Upload this project.
3. Do NOT upload `.env` files or passwords.
